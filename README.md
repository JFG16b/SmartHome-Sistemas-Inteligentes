# SmartHome-Sistemas-Inteligentes

# GUIA DE INSTALACIÓN #
Para realizar la instalación del sistema inteligente debes unicamente descargar la carpeta SmartHome o el fichero ejecutable prueba.jar.

# INSTRUCCIONES DE EJECUCIÓN #
Para ejecutar la aplicación tienes dos opciones descargarte el ejecutable o descargarte la carpeta del proyecto:
En el caso de descargar el ejecutable, seria necesario unicamente darle doble click izquierdo al archivo jar.
SI quieres hacerlo con la carpeta debes de abrir el proyecto en eclipse y darle a run con la clase main.

# DATOS DE EJEMPLO #
Los datos que envian los sensores de percecpción no estan predispuestos, son generados aleatoriamente de manera cíclica cada x tiempo. Siendo x diferente para cada sensor. Con esto aseguramos que durante la ejecución se pueda observar como ante distintos datos se observa como el programa maneja los cambios.
